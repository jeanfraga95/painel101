Importar banco de dados
Esta ferramenta importa revendas e usuários SSH de um backup MySQL do Dragon Core / Atlas para o Painel Master.
  • Aceita arquivos .sql ou .sql.gz
  • Revendas são importadas mantendo hierarquia (pai → filho)
  • Usuários SSH são vinculados à revenda correspondente
  • Usuários/revendas já existentes no painel são ignorados
  • Servidores não são importados — cadastre manualmente após a migração
Atenção: Execute a migração apenas uma vez. Rodar duas vezes pode criar duplicatas de senha.

Após a migração
  1. Cadastre os servidores SSH em Servidores
  2. Instale os módulos em cada servidor
  3. Atribua servidores às revendas em Revendas
  4. Sincronize os usuários com cada servidor
  5. Oriente as revendas a trocar as senhas
